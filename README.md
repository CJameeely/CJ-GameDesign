# CAT — First Playable

一个关于同时照顾三只不同性格猫咪的浏览器判断游戏。玩家不能读取隐藏数值，需要通过叫声、身体语言、位置与环境状态判断每只猫真正需要食物、玩耍、接触还是空间。

## 运行

本项目使用 **Track A：原生 HTML / CSS / JavaScript**，没有第三方依赖与构建步骤。

```bash
python3 -m http.server 8000
```

打开 `http://localhost:8000/`。也可以直接打开 `index.html`。

## 操作

1. 选择一个挑战并开始。
2. 点击房间中的猫，阅读可见观察描述。
3. 选择喂食、陪玩、主动抚摸、留出空间、清理猫砂或暂时分开。
4. 每天行动次数有限；点击“结束今天”推进时间。

## 主要变量

- 环境数据：食盆、猫砂、活动线索、猫咪距离。
- 玩家控制：目标猫和照护行动。
- 系统计算：`hunger`、`energy`、`stress`、`trust`、群体 `tension`。
- 反馈映射：叫声表示未满足需要；耳朵、姿势、躲藏和靠近表示压力与信任；物件外观表示环境状态。隐藏数值不会直接显示给玩家。

所有站内链接与资源路径均为相对路径，适用于从仓库根目录发布 GitHub Pages。
